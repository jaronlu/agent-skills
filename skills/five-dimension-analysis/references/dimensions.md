# 五维提问清单 · 证据标准 · 认知陷阱

执行 Step 1 时读取本文件。每维填三栏：**证据 / 推断 / 空白（未知）**。

## 证据强度分级（贯穿全表）

| 级别 | 含义 | 可支撑什么 |
|---|---|---|
| **一手** | 亲历、原始文件、当事人原话 | 可作为结论依据 |
| **二手** | 他人转述（须标注来源人与其立场） | 只能作为线索，须交叉验证 |
| **推测** | 由行为反推、由常理推演 | 只能进入「推断」栏，不得进入结论 |

来源人的立场必须记录——利益相关者的证词权重应下调，反对者的证词反而常更可信。

## 史 · 时间线

**核心提问**

- 这件事从什么时候开始？关键节点有哪些？
- 以往同类情况怎么处理？处理结果如何？
- 现行做法最初是为解决什么问题而设？那个问题还在吗？
- 谁在现行格局中获利？（惯性的真正来源是受益者，不是"传统"）
- 有没有曾经尝试但失败的方案？失败原因是什么？

**有效证据**：时间线文档、会议纪要、人事/任期变动时间、历史先例的处理结果、预算与编制的历年变化。

**认知陷阱**

- 把"相关"当"因果"——先后发生不等于因果。
- "一直如此"不等于"理应如此"。
- 幸存者偏差：只看到延续下来的做法，看不到被淘汰的方案。
- 忽略"沉默的历史"：失败案例通常不被记录，导致高估当前做法的合理性。

**应写「未知」的信号**：拿不到完整时间线、无法确认关键节点的决策人。

---

## 经 · 利益链

**核心提问**

- 谁得利（直接 / 间接）？谁受损？
- **谁维持现状即得利**？——沉默方往往是最坚定的现状维护者。
- 各方的时间偏好：谁急于兑现？谁能耗得起？
- 让步的真实代价由谁承担？

**账本不止是钱**，还包括：面子、权力、资源分配权、安全感、风险规避、考核指标（**KPI 决定行为**）、职业声誉、退路。

**认知陷阱**

- 用自己的偏好推测对方的账本（最常见的错误）。
- 混淆「组织的账」与「决策者个人的账」——两者冲突时，通常个人账胜出。
- 只看增量，忽略"沉没成本"带来的非理性坚持。

**定位真账本的技巧**：找「谁为此付钱 / 谁会因此被问责」。付钱方与问责方通常才是真正的利益主体，而非名义上的提案方。

**应写「未知」的信号**：不清楚各方的考核指标或预算归属。

---

## 政 · 权力图

**核心提问**

- 谁真正拍板？谁影响决策？谁只是执行？
- 谁能**否决**（而非提案）？
- 谁能**延迟**？（拖延权常被低估，等同于软否决）
- 信息怎么流？谁被排除在会议 / 邮件抄送之外？

**有效证据**：谁的意见被反复引用；谁能推翻已定事项；谁参与非正式沟通（饭局、私聊、临时小会）；谁出现在关键邮件的抄送列表。

**认知陷阱**

- 把组织架构图当成权力图（二者系统性不一致）。
- 忽略流程守门人——法务、财务、合规、秘书、IT 权限，都拥有实质否决权。
- 忽略外部权力：监管、大客户、股东、舆论。
- 把"影响力"等同于"决策权"。

**判据**：**谁能说"不"并且真的停得下来，谁才是决策者。**

**应写「未知」的信号**：无法观察到否决事件的实例，只能看到表面的会议层级。

---

## 军 · 博弈局

**第一个问题永远是「该不该打」，而不是「怎么赢」。**

**核心提问**

- 谁进攻？谁防守？谁在结盟？结盟的稳定性如何？
- 时机窗口：什么时候筹码最大？窗口何时关闭？

**筹码清单（逐项自评）**：资源 / 信息差 / 时间（能否耗）/ 盟友（及其可靠性）/ **退路**（可承受失败的能力）。

**认知陷阱**

- 高估自身不可替代性（几乎人人高估）。
- 把"我有道理"当成筹码——道理不是筹码，只是说服工具。
- 忽略对方的退路可能比自己多。
- 忽略"不参与"也是一种策略，且常常是最优解。

**判据**：若筹码不足以改变对方的账本，博弈不成立，应转为等待、结盟或退出。

**应写「未知」的信号**：不清楚对方的退路与底线，或无法评估盟友的可靠性。

---

## 哲 · 本质层

**核心提问**

- 这到底是哪类问题？（成本 / 权力 / 转型 / 情绪 / 规则 / 人性 / 周期）
- 去掉表面噪音后，根本矛盾是什么？
- **它不是什么？**（反向界定，比正向断言更可靠）

**合格线（硬性）**：必须推出至少一个**可观察的预测**。推不出则本格判无效，重写。

**空话检测**：若某句话放到任何事件上都成立（如"本质是利益""本质是人性"），即为空话，删除。

**常见本质类型（作为候选，不直接套用）**：增长模式到顶、权力交接、成本结构失衡、激励/规则错配、周期性回归、个人焦虑外溢、技术替代。

**应写「未知」的信号**：只能提出一种解释，且提不出任何竞争性解释。

## 典型维度冲突与裁决

| 冲突组合 | 常见情形 | 裁决倾向 |
|---|---|---|
| 经 vs 政 | 方案对组织有利，但拍板者个人账不划算 | **政胜**（个人账优先于组织账） |
| 史 vs 军 | 惯性很强，但出现明确窗口 | 短期军可破局，长期仍回归史的惯性 |
| 经 vs 史 | 利益上应该改，历史上从未改成 | 取决于拍板者是否更换；未换则史胜 |
| 军 vs 哲 | 战术上可赢，但本质是必输的方向 | **哲胜**：先转译为可观察信号，再决定是否退出 |
| 政 vs 军 | 决策者支持，但执行层面集体抵制 | 看抵制方是否掌握流程否决权；掌握则军胜 |

> 该表为经验归纳，用于快速定位，不是定律。出现与规则相悖的强证据时，以证据为准。
