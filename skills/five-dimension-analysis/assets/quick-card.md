# 一页速用版（挂墙 / 贴桌面）

## 流程

事件 → 事实 → 五维 → 裁决 → 反证 → 动作 → 回看

## 五问（按这个顺序，不许跳）

1. **来路**：从什么时候开始？以前怎么处理？　　　→ 史
2. **账本**：谁得利？谁受损？谁维持现状？　　　　→ 经
3. **拍板**：谁真说了算？信息流向？谁被排除？　　→ 政
4. **博弈**：谁进攻谁防守？我筹码够吗？**该不该打**？ → 军
5. **本质**：这到底是哪类问题？**它不是什么**？　　→ 哲

## 三条硬约束

- **事实先于结论**：没有证据就写「未知」，禁止脑补。
- **判断用概率词**：倾向 / 可能 / 尚需验证。禁用「必然 / 一定」。
- **每次必写反证**：出现什么，我就错了。写不出 = 这是信念不是分析。

## 冲突时的优先级

事实 > 推断　｜　短期看**经**　中期看**政**　长期看**史**　｜　军是约束不是目标　｜　哲要先转译成可观察信号

## 输出三步（防鸡汤）

1. 先写**事实**，不下判断。
2. 再写**可能**，不写必然。
3. 最后只写**动作**：≤3 件具体事（谁 / 做什么 / 何时 / 完成标准）。「不出手」是合法答案。

## 自检（任一命中即作废重来）

- [ ] 结论里有"本质就是人性"
- [ ] 五格全满但没一条标来源
- [ ] 只输出洞察，没有下一步
- [ ] 超过 30 分钟还在打转（→ 停下，先补信息）

## 回看（30 天后，唯一能让框架变准的动作）

哪一维猜错了？为什么？下次权重怎么调？
