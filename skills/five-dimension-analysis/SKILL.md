# 五维分析（史 · 经 · 政 · 军 · 哲）

## 目的

把「事后解释型叙事」改造成「可证伪的决策清单」。

该框架的价值不在于让分析显得深刻，而在于**防止自欺**。五维思维最大的失效模式是：任何结果都能被五个维度编出一套自洽解释——能解释一切的模型，等于什么都没解释。本 skill 的全部约束因此指向同一目标：**让每条判断都可能被证明是错的**。

## 资源索引

按需加载，避免一次性占用上下文：

| 资源 | 用途 |
|---|---|
| `references/dimensions.md` | 五个维度的完整提问清单、常见认知陷阱、有效证据类型。**执行 Step 1 时读取。** |
| `references/worked-example.md` | 一份填好的示范（含哪些格子应留「未知」）。**首次使用或拿不准格式时读取。** |
| `assets/analysis-template.md` | 空白分析表，复制后逐格填写，作为交付给用户的主要输出。 |
| `assets/quick-card.md` | 一页速用卡，供用户贴桌面/挂墙，不用于加载到上下文中。 |

## 四道铁律（每次分析必须满足）

| 关卡 | 要求 | 不通过的表现 |
|---|---|---|
| **可证伪** | 写出「出现什么事实，本判断就错了」 | 全是"本质就是…"，无法被推翻 |
| **可裁决** | 维度冲突时按规则定优先级，不靠感觉 | 五维各说各话，最后仍靠拍脑袋收场 |
| **可操作** | 产出 ≤3 个具体动作，「不出手」为合法选项 | 输出一堆洞察，没有下一步 |
| **可校准** | 设定回看日期，事后记录哪一维猜错 | 用一次即结束，永远无法变准 |

## 执行流程（六步，单次控制在 20–30 分钟内）

### Step 0 · 事实层：先写事实，不下判断

只列**可验证**信息，逐条标注来源与可信度：

- `[事实]` 亲眼所见 / 一手文件 / 当事人原话
- `[转述]` 二手信息，标注来源人及其立场
- `[未知]` **无证据即写"未知"，禁止脑补填充**

事实层写不满说明**信息不足**，而非分析不足。此时正确动作是补信息或降低结论强度，不是继续往下推演。

### Step 1 · 五维扫描

读取 `references/dimensions.md` 获取每维的完整提问清单。

每维必须三栏齐全：**证据 / 推断 / 空白（未知）**。

**哲维合格线**：必须能推出至少一个**可观察的预测**；推不出则判为无效，删除重写。

### Step 2 · 冲突裁决

> 以下为经验规则（推断，非定论），作用是逼出结论，不是真理。

1. **事实 > 一切推断**：任一维度无证据支撑，不得进入最终结论。
2. **短期看经**：人按账本行动，利益是最可靠的短期预测器。
3. **中期看政**：谁能拍板，决定事情最终走向。
4. **长期看史**：路径依赖通常压倒个人意志。
5. **军是约束，不是目标**：筹码不足时，正确动作是不出手、等待或结盟。
6. **哲不直接产出行动**：本质判断须先转译成可观察信号，方可指导动作。

### Step 3 · 反证信号（最关键，不可省略）

写一条：**「如果 __（可观察事件）__ 在 __（时间）__ 前发生，则「__（某条判断）__」为假。」**

写不出反证信号，说明该判断是信念而非分析。

### Step 4 · 动作清单（≤3 条）

每条具体到：谁、做什么、何时、完成标准。

允许且鼓励输出「本次不出手。原因：__。等待触发条件：__」。

### Step 5 · 回看（校准闭环）

设定回看日期（建议 30 天后），记录哪维猜对、哪维猜错、权重如何调整。

若用户希望在到期时被自动提醒，使用 automation 工具创建一次性任务，提示词写明待回看的事件与判断。

## 输出格式

复制 `assets/analysis-template.md` 填写后交付。Step 0、Step 3、Step 5 不可省略——这三步构成"防鸡汤"的全部保险。

交付时：

- 结论先行（一句话），随后给依据，最后给动作。
- 严格区分「事实 / 推断 / 未知」，标明哪些须由用户自行核实。
- 主动指出信息缺口所在，以及最该先补哪一条。

## 反模式（出现任一即判本次分析失败）

1. 结论中出现"必然""一定""毫无疑问"——改用"倾向 / 可能 / 尚需验证"。
2. 五格全填满，但没有一条标注来源。
3. 以"本质是人性 / 本质是利益"结案。
4. 只输出洞察，不输出动作。
5. 用五维给一个已经拍脑袋定下的结论做背书。
6. 超过 30 分钟仍在打转——信息不足则停下补信息。
