# 第一性原理案例库

使用规则：

1. 本库用于演示推理结构，不为其中的历史报价、估算或逸闻背书。缺少原始出处时标为**【未核实】**，不得作为推导前提或对外事实。
2. 标为**【已核实原出处】**须记录并核对原始链接或完整书目信息、页码 / 段落 / 时间戳，以及数字的时间点和口径。可追溯的线索不等于完成核实。
3. 区分理论约束、经验输入、假设与本轮推断。材料成本估算不自动包含人力、良率、认证、可靠性或资本摊销；引用时不得把估算升级为可实现成本或行业事实。

---

## 案例 1：SpaceX — 从材料估算提出待验证问题

- **待检验主张【未核实】**：常见转述把 2012 年前后的单次发射报价约 6500 万美元、火箭材料价值约为售价 2% 归于马斯克。前者缺少原始报价文件，后者待核对 WIRED 访谈《Elon Musk's Mission to Mars》（Chris Anderson）的原文定位、估算口径和产品边界；两项数字不能据此视为同口径。
- **经验输入要求**：要估材料采购基线，须先定义火箭型号、任务 / 配置、材料清单、用量、采购时点与价格口径。仅指出相关材料有市场报价，并不能推出整箭材料成本；不同材料也不一定对应同一种公开现货市场。
- **另一个未核实示例**：常见转述称某半喷管外套壳报价 13,000 美元、钢材约 200 美元，商值约 65。缺少原始出处、年份、部件定义及制造边界；即使算术成立，也只能说明这组输入的比值，不能证明该差额可消除。
- **结论边界（条件式推断）**：若经过核实，特定型号与任务配置下的材料采购成本显著低于同边界的售价，这只能提示进一步调查制造、测试、质量、研发、合规、供应链与利润等项目。它不能证明存在同等幅度的可降本空间，更不能证明售价可降至材料成本。

## 案例 2：特斯拉电池 — 材料估算与成本口径

- **待检验主张【未核实】**：常见叙述称 2013 年前后电池组价格约 600 美元/kWh、85 kWh 电池组超过 50,000 美元，并把约 80 美元/kWh 的材料估算归于马斯克。现有线索包括 2012 年 Kevin Rose 访谈和 2013 年 TED 演讲，但尚无对应原文定位、估算时间、化学体系、产品边界或价格口径。
- **经验输入要求**：按具体电芯化学体系、结构和目标产量确认物料清单及用量，再核对相应时点的商品或供应商价格；不能假定所有材料都有 LME 现货价，也不能把电芯、模组、电池组成本混为一谈。
- **结论边界**：只有当售价与材料估算的时间、产品边界、产量、币种及成本口径可比时，才可计算两者差额。当前输入未核实，不应据此报告约 520 美元/kWh 的差额。即使差额核实，它也可能包含加工、良率、研发、质保、资本分摊和利润，不能直接视为可降本空间。
- **动作线索【未核实】**：自建电池厂与规模制造常被描述为后续动作。若要用作历史论据，应回查公司原始公告并注明项目、时间和实际产能；不能仅凭叙事建立因果关系。

## 案例 3：狭义相对论 — 公设、背景与推导需分开

- **可核实的一手文本**：爱因斯坦 1905 年论文《论动体的电动力学》（Zur Elektrodynamik bewegter Körper）提出相对性原理与光速公设。引用具体表述或推导时，应核对论文原文及所用译本；本文不把未标注来源的概述当作逐字引文。
- **历史背景需限定**：运动导体 / 磁体问题、迈克耳孙–莫雷实验以及洛伦兹、菲茨杰拉德的工作常被用作背景介绍，但不能仅凭这些概述说它们单独推出了狭义相对论，也不应把以太理论简单写成无意义的“补丁”。
- **推导边界**：时间膨胀和长度收缩可在相对论的时空变换及测量定义下推导。质能关系涉及能量与质量的定义和推导条件，不宜不加限定地说所有相关结果都只是两条口号的直接必然结论。
- **可复用点（本轮推断）**：重建理论时，要明确公设、数学推导、实验支持与历史解释分别扮演什么角色；不能把教学摘要冒充完整的科学史论证。

## 案例 4：五个为什么 — 追问不是因果证明

- **方法说明**：五个为什么常与丰田生产方式和大野耐一相关联；具体出处应按采用的版本核对。这里不提供可验证的丰田现场案例。
- **示例链【假设示例，非历史案例】**：机器停机 → 轴承过热 → 润滑不足 → 油泵供油异常 → 滤网堵塞。此链仅演示追问形式；每个箭头都需要维修记录、检查或实验支持，不能因连续问“为什么”就认定找到了根因。实际问题可能有多条因果路径，追问次数也不必固定为五次。
- **可复用点（本轮推断）**：把“规定如此”继续拆成适用目标、制定依据与当前约束，并查证这些条件是否仍成立。不要预设惯例一定源于过时约束，也不要在未验证原因前承诺整改效果。

## 案例 5（反面演示）：下钻到哪里停

不同分析层级回答不同问题；下钻本身不会自动得到产品成本下限：

- 产品 / 报价层：单次发射报价约 6500 万美元。【未核实：沿用案例 1 的历史估算线索】
- 固定物料层：材料市值约为售价 2%。【未核实：沿用案例 1 的估算线索；重复引用不增加证据】
- 上游能源层：若材料方案涉及原铝，可进一步研究电解能耗与电价；本库不提供已核实的能耗数值，也不假设该因素对当前决策重要。

**停止深挖的依据应是决策敏感性，而不是“已经找到下限”。** 只有当更细一层的数据可能改变方案排序、可行性判断或行动选择时，才继续收集；否则记录未知项及其对结论的影响。前述报价和材料估算均未核实，不能用来证明垂直整合有降本空间。

## 引用纪律

1. 每个关键数字写明**数值 + 时间点 + 口径 + 来源 + 核实状态**；适用时注明不确定性。
2. 外部决策若依赖某数字，回到原始出处核对；原始出处不可得时明确标为未核实，不得把二手转述升级为事实。
3. 「马斯克说过」不等于「物理上成立」；同理，「所有人都这么做」也不等于「必须这么做」。
