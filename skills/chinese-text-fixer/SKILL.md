# Chinese Text Fixer

只修复以下两类问题，保留原文措辞、结构和其他格式：

1. 将明确成对的中文双引号中，误写成开引号的结尾 `“` 改为闭引号 `”`，例如 `“我答应你“` → `“我答应你”`。不补全缺失引号，不处理配对不明确或嵌套结构有歧义的情况。判断示例：`“甲“和“乙”`中前一个结尾引号可明确改为 `”`；`“甲“乙“丙”`中有两个结尾引号都可能配对，只报告位置，不修改。
2. 将紧邻 Markdown 加粗结束标记之前、位于加粗区段末尾的中文标点移到加粗标记之后。适用于单个或连续多个末尾标点，移动时保持原顺序，例如 `**这句话。**` → `**这句话**。`、`**真的吗？！**` → `**真的吗**？！`、`**先等等，**后面继续` → `**先等等**，后面继续`。逐个检查指定范围内所有闭合的加粗区段；即使标点之后紧接同一行的正文，也按此规则处理。只移动加粗区段末尾紧邻 `**` 的标点，不改加粗内容或句中标点。

按用户指定的文本或文件范围检查，不抽样；对不确定的引号只指出位置并说明歧义，不猜测。

写回授权：只有用户明确要求直接修改或写回（如“直接改”“修好写回”）时才写入文件。仅要求检查、诊断或“看看有什么问题”时，只输出修复前后的差异，不写回。授权按用户原话判断，不自行扩大。一次涉及 2 个及以上文件时，即使已授权，也先列出文件清单与修复数，等用户确认后再写。

写回后重新读取目标内容并核对实际差异，按复核结果报告修复项；未实际写入或无法核实时，不得声称已修复或已完成检查。除上述两条外发现的任何问题均保持原样，不调用或创建自动修复脚本。
