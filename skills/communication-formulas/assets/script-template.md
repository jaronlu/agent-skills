## B. FAB 说服

- **F 特征**（客观属性，无形容词）：
- **A 优势**（相比 ______，好在哪）：

**合格性检验**：
- [ ] 把 B 的"你"换成"我们"，句子是否不成立？（成立则重写）
- [ ] 删掉 B 后，说服力是否下降？（不下降则 B 是废话）

## 交付前四道铁律自检

- [ ] **可验证**：事实拍得到吗？利益数得清吗？
- [ ] **利益归对方**：把"我们"全换成"你"，换不了的删掉。
- [ ] **结论可独立**：首句单独拎出来还有信息量吗？
- [ ] **结尾有增量**：最后一句是下一步，还是复读？
