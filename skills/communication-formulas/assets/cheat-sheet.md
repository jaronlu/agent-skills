# 五大沟通公式 · 速查卡

> 打印或存手机。开口前 10 秒扫一眼，只做两件事：**选公式 → 填格子**。

## 选公式：先看目的，不看场景名

| 我要对方…… | 用 | 顺序 |
|---|---|---|
| 做决策 / 采纳建议 | **SCQA** | 情景 → 冲突 → 问题 → 答案 |
| 接受方案 / 掏钱点头 | **FAB** | 特征 → 优势 → 利益 |
| 改变行为 / 还不翻脸 | **BACC** | 事实 → 感受 → 方案 → 后果 |
| 愿意继续聊下去 | **3W** | 做什么 → 来自哪 → 为什么在这 |
| 记住并引用我的观点 | **PREP** | 观点 → 理由 → 例子 → 重申 |

**撞车时**：要改行为→BACC；要决策→SCQA；要掏钱→FAB；只要记住→PREP；还不熟→3W。一次只用一套。

---

## SCQA · 汇报求决策

- **S 情景**：双方都认的事实，一句话。"过去三个季度，__ 一直是 __。"
- **C 冲突**：一个具体变化，带数字。"但从上月起，__ 变成 __，__ 已受影响。"
- **Q 问题**：用对方的口吻问。"所以问题是：怎么在 __ 前把 __ 拉回 __？"
- **A 答案**：三步动作 + 单点决策请求。"需要您定的就是 __ 这一件事。"

> 向上汇报默认 **答案前置**（A-S-C-Q），先说结论再补背景。
> 禁忌：S 写成工作日志；冲突是废话（"面临新的挑战"）；答案只有方向没有动作。

## FAB · 说服

- **F 特征**：不含形容词的客观属性。"这套流程会先给请求打优先级标签。"
- **A 优势**：必须有对比对象。"相比现在的先到先处理，紧急请求能插到前面。"
- **B 利益**：主语是"你"，可量化。"你的团队不用再为插单加班，每周约省 __ 小时。"

> 检验：把 B 的"你"换成"我们"还成立？成立 → 写的是我方优势，重写。
> 禁忌：停在 F；优势没有对比对象；利益写成"这能帮我们拿下单子"。

## BACC · 反馈

- **B 事实**：**摄像头能拍到**。"周二评审会上，你在李工讲到第三页时打断了他，接着讲了约五分钟。"
- **A 感受**：对工作的具体后果，用"我"开头。"会后又花时间重新对齐了一遍。"
- **C 方案**：下一句该说什么，具体到句式。"下次能不能等对方讲完再补充？"
- **C 后果**：改了有什么好处。"这样评审能一次过，你也不用会后返工。"

> 重写对照：你态度不好 → 你把笔记本合上、往后靠了一下、全程没发言。
> 禁忌：三明治（表扬-批评-表扬）；"你总是…"；反馈攒到季度。

## 3W · 破冰（30–45 秒 + 钩子）

- **What**：不说职位名词。"我在做 __，简单说就是帮 __ 解决 __。"
- **Where**：给一个可接的锚点。"我原来在 __ 做 __，这次从 __ 过来。"
- **Why**：说真实原因，带点个人色彩。"这次主要是想看看 __ 是怎么做的。"
- **+ 钩子**：抛回开放式问题。"你呢，是怎么关注到这场活动的？"

> 是自述结构，不是提问清单。连问三个问题 = 查户口。
> 禁忌：背简历；"来学习学习"；说完不抛钩子。

## PREP · 发言

- **P 观点**：单独抽出来仍成立。"我建议把发布时间推迟一周。"
- **R 理由**：2–3 条，回答"为什么这对听众重要"。"一是 __，二是 __。"
- **E 例子**：有数字、有具体时间地点。"上月 A 组提前发版，回滚用了两天。"
- **P′ 重申**：**升级**为请求/下一步/钩子，禁止复读。"今天想请您定一下。"

> 区分 R 与 E：删掉后主张站不住的是 R，能删的是 E。
> 禁忌：观点含糊（"可能需要再讨论"）；理由超过三条；首尾一字不差。

## 四道铁律（开口前过一遍）

1. **可验证** —— 事实拍得到吗？利益数得清吗？
2. **利益归对方** —— 把"我们"全换成"你"，换不了的删掉。
3. **结论可独立** —— 首句单独拎出来还有信息量吗？
4. **结尾有增量** —— 最后一句是下一步，还是复读？

## 一句话提醒

公式只管**顺序**，不管**真假**。结构能让一个好理由更清楚，也能让一个坏理由更体面——别用它包装自己都不信的话。
